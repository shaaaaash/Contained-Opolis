### Changes
- Updated to NeoForge 21.1.242
- Updated all Mods to the latest versions
- Fixed Just Dire Things server config not having the correct minimum machine tick speed value
- Made Integrated Dynamics default to 20 ticks/operation
- Mentioned in the hammer quest that the hammers can pick up Mysterious Blocks
- Increased the Gem Finder durability to 65535 so that it doesn't break that soon
- Changed Rechiseled: AE2 to Rechiseled: Applied Energistics 2 to enable autocrafting chiseled blocks in the AE2 system
- Added Collapsible Groups mod to organize JEI bit with some custom groups
- Disabled /spawn command use /playerspawn or /sky spawn instead to get to the spawn
- Fully removed unused Mystical Agriculture Essences recipes from JEI
- Added Discord Rich Presence
- Added Explorer's Compass to replace Structure Compass because it was crashing if hovered over in the Storage Terminal
